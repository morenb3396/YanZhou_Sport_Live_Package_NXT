# 烟洲体育直播包装 NXT

面向校园运动会和球赛的本地导播台与 OBS 透明图层。沿用 `YanZhou__Live__pkg_NXT-main` 的 Node.js 本地服务、WebSocket 状态同步、导播台和输出页分离的做法。正式赛事、名单、计时、成绩、比分和图层设置保存在本机。

## Windows 便携包

1. 将 `YanZhou-Sport-Live-NXT-1.5.2-Windows-x64.zip` 完整解压到有写入权限的目录。
2. 双击 `start.cmd`。浏览器会打开 [导播台](http://127.0.0.1:3120/control.html)。直播期间请保留启动窗口。
3. 在 OBS 添加「浏览器」来源。保持「本地文件」关闭，URL 填 [输出地址](http://127.0.0.1:3120/overlay.html)，宽 **1920**、高 **1080**。将浏览器源放在摄像机来源上方。
4. 如要提高计时牌刷新率，可跟随 OBS 的输出帧率把浏览器源设为 **60 FPS**。保持「不可见时关闭来源」与「场景激活时刷新浏览器」关闭。[OBS 浏览器来源文档](https://obsproject.com/kb/browser-source)

导播台的棋盘格、深灰和跑道只是监看底图。将透明输出地址添加为 OBS「浏览器」来源后，空白区域会透出下方的视频。普通浏览器窗口由桌面提供底色，直播叠加请直接使用浏览器来源。

便携包内置 Windows x64 Node.js 与 WebSocket 依赖，解压后可离线运行。导播台和 OBS 在同一台电脑上使用。若 3120 端口已被占用，可在 PowerShell 中运行 `$env:YANZHOU_PORT = '3121'` 和 `.\start.cmd`，再用导播台复制新地址。

## 一屏导播

顶部可在「男子」「女子」之间切换，再从当前组别选择赛事。切换组别时优先进入同项目、同轮次的赛事。新增赛事时可以指定比赛组别和轮次。左侧工作台用同一张表搜索选手、记完赛和排名，「备赛名单」页签可准备其他组。右侧是节目监看和上屏开关。名单较长时可翻页，窄屏可用页签切换工作台与输出。

每场赛事保存自己的名单、计时、排名、图层位置、显隐、翻页、挂角和公告。切换赛事会自动把对应配置送到节目监看和同一个 OBS 输出地址，切回后恢复该场状态。仍在运行的计时会继续走表。升级旧版时，已有赛事和成绩会保留，原先的共享布局会用作各场初始布局，已上屏的名单、成绩和文字归入原先的当前赛事。

点击输出区的「位置和样式」，可选择图层并调整位置、大小、透明度和动画。默认位置与四角按钮对齐到监看的安全区。选四角时，过大的图层会缩到能放进安全区的尺寸。监看底图与安全区可在监看顶栏控制。左上挂角使用原项目校徽和绛红色 YZBTVS 字标，右侧配较小的 SPORT。可在「直播信息」填写挂角副标题和榜单页脚。

## 第五届「烟伙杯」校运会

赛事列表默认加载本届校运会的 49 个条目。方案中 11 月 27 日、28 日有 42 场正式排期。高一、高二男子 1000 米和两个年级的男女子 1500 米列为时间待定。教职工团体赛放在 27 日下午，支持先导入队伍。以正式秩序册为准，可用「编辑赛事」调整开赛时间。赛程会提前 25 分钟显示检录时间。

1. 在「赛程」按时段、年级筛选，点「名单」可先备赛，点「切换」才会切换实际输出。名单支持 CSV 或直接粘贴 Excel 表格，单位填写班级。
2. 径赛名单可填「分组」「道次」。控制区的「计时分组」会切换本组时钟和检录名单。停表后查看全场跨组名次。100 米、200 米预赛确认名次后可用「晋级到决赛」生成对应的决赛名单，再按秩序册分配道次。
3. 跳远、铅球在选手行点「记试次」，铅球标注男子 5 kg、女子 4 kg。跳高女子 95 cm、男子 130 cm 起跳，分别到 115 cm、150 cm 后每档增加 3 cm。可逐人记过杆、失败、免跳和撤销上次。
4. 50 米迎面接力按班级或队伍导入，每队 10 人，男、女各 5 人。填人数后工作台会标记核验状态，可按裁判决定处理资格。4×100 米接力同样按队伍记录成绩。
5. 决赛核对名次和班级后点「确认计分」。班级积分按年级汇总，个人项前八名为 9、7、6、5、4、3、2、1 分，接力双倍。已确认决赛中超过原校纪录的最高有效成绩获得双倍计分。仍同分且破纪录数和各名次次数相同的班级标记「待抽签」。班级积分可上屏或导出 CSV。

## 赛前导入与赛后排名

1. 在「备赛名单」页签的「名单归属」选择目标组，再导入 CSV。可用「创建待播赛事」先建下一组，当前画面会继续播出。
2. 切换到目标赛事。赛后把选手拖到表内的蓝色落点即可追加名次，拖到已排名的两行之间可换位。也可用行末的「入榜」「撤回」，聚焦已排名选手的拖动手柄后按 ↑ / ↓ 可微调名次。
3. 点「成绩榜上屏」。之后调整名次会即时更新 OBS 和导出的 CSV。只确认名次时，成绩列显示 `—`。填入时间或距离后会随名次显示。
4. 按成绩排序可继续使用。点击「恢复按成绩」会清除手动名次，并根据已录入的计时或田赛成绩重新排名。

## 1000 米现场操作

1. 选择「1000 米」，用「编辑赛事」设置组别、赛场和跑道每圈距离。不同组次可各建一项。预设为 400 米跑道，领跑选手的通过点是 **200 m、600 m、1000 m**。
2. 添加选手或导入 CSV。点「显示参赛名单」上屏，每页六人，右侧模块可翻页。
3. 发令时点「开始计时」。领跑者到达通过点时点「记录通过」，最后点「记录头名冲线」。通过点可逐条撤销。
4. 各选手过线时点其所在行的「记完赛」。所有选手录完后点「结束计时」。错过的时间可在「编辑选手」里手工补录或更正，也可录入 DNS、DNF、DQ。
5. 赛后可在「名次」里确认手动名次，或按用时从短到长计算名次。同成绩在自动排序时并列。点「冠军上屏」播出，可导出 CSV 给赛事组委会。

「校时」适用于待发、暂停和结束状态。「重置计时」清除本项计时和通过点。现场计时由导播员手动触发，也可录入裁判成绩后播出。

## 其他预设与图层

- **径赛**包含男女子 1500 米等赛事预设。1500 米默认每圈 400 米，通过点为 **300 m、700 m、1100 m、1500 m**。可用 50、100、200、400、800、1000 米和接力预设新建赛事，也可自定义距离、每圈长度和棒数。
- **田赛**包含男女子铅球、跳远、跳高和自定义项目。逐次录入距离、犯规或放弃，成绩榜按最佳有效成绩排序，同成绩并列。
- **球赛**保留足球与自定义球赛，支持加减分、切节、校时、比赛比分上屏和导出。启动新版时会从旧设置里移除篮球项目。
- **通用图层**包含 Logo 挂角、赛事条、选手人物条和公告。打开「位置和样式」后可在监看里拖动已上屏的图层。监看背景与安全区仅用于导播台。「一键清屏」可隐藏正式输出中的全部图层。
- **彩排模式**在导播台顶栏，提供示例名单、独立数据文件和带「彩排」标记的输出页。正式直播时用不带 `mode=demo` 的 OBS 地址。

## CSV 与数据

「导入 CSV」提供模板，支持文件与粘贴。首行至少含 `姓名`，其他可用表头为 `道次,号码,单位,成绩,状态,试次`。号码可留空，填写时同组号码须唯一。文件支持 UTF-8 或 GB18030，字段含逗号时使用双引号。

```csv
道次,号码,姓名,单位,成绩,状态
1,101,示例选手,一班,03:21.52,ok
2,102,示例选手二,二班,,DNS
```

径赛成绩可填 `03:21.52` 或秒数 `201.52`。田赛可填成绩 `5.32`，也可在「试次」列填写 `5.10|X|5.32`，`X` 表示犯规，`-` 表示放弃。正式数据写入 `data/settings.json`，彩排数据写入 `data/rehearsal.json`。可在退出后备份整个 `data` 目录。服务重开后恢复上次状态，处于计时中的时钟按原起表时间继续计算。

## 从源码启动和打包

需要 Node.js 22 以上版本。

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
```

`npm.cmd start` 后手动打开导播台。运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\package-windows.ps1` 生成 `dist` 下的 Windows 便携 ZIP 及 SHA-256 校验文件。构建使用 [Node.js v24.22.3 Windows 发行包](https://nodejs.org/en/blog/release/v24.22.3/)，运行时许可证随包分发。

导播台跑道背景由 ImageGen 生成，用于检查不同图层的遮挡和对比度。
